# 魔方还原助手 (rubik-tool)

纯静态的魔方还原辅助网页工具。把魔方 54 格按实际颜色涂好，即可求解还原步骤。

## 功能
- 真实 3D 魔方：基于 Three.js（WebGL）渲染，黑色塑料体 + 内嵌彩色贴纸，拖拽可自由旋转视角，空闲时缓慢自转
- 真实转动动画：转层时整层作为刚性圆盘绕魔方中心轴平滑旋转（缓动），而非旧版的各块乱转
- 涂色辅助：对照真实魔方逐格选色
- 自动推断：涂一格后按魔方物理规则自动补全同块其他可确定的格子（绿色描边标记）
- 错误诊断：一键标红违反魔方规则的格子并提示原因
- 复制配色：把当前 54 格配色复制成文本，方便排查
- 求解还原：基于 Kociemba 两阶段算法生成最短还原步骤，3D 动画逐步引导

## 使用
浏览器直接打开 `index.html` 即可。**需与本目录下的 `three.min.js` 放在同一文件夹**（两者一起才是完整工具）。

- 离线可用：所有依赖（`three.min.js`、求解器）都是本地文件，运行时无需联网。
- 首次打开请让它加载同目录的 `three.min.js`（若单独移动 `index.html` 请一并带上 `three.min.js`）。

## 技术说明
- 3D 渲染：Three.js r128（`three.min.js`，已随仓库提供，非 CDN 依赖）
- 求解：Kociemba 两阶段算法（rubik-solver，内联在 HTML 中）
- 坐标模型：cubie 模型（8 角块 + 12 棱块），与标准 facelet 记号一致

## 来源
本工具原为「拾遗集」站点（resource-hub）中的页面，抽出来作为独立版本。
