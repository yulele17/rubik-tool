# 魔方还原助手 (rubik-tool)

纯静态、单文件的魔方还原辅助网页工具。把魔方 54 格按实际颜色涂好，即可求解还原步骤。

## 功能
- 涂色辅助：对照真实魔方逐格选色
- 自动推断：涂一格后按魔方物理规则自动补全同块其他可确定的格子（绿色描边标记）
- 错误诊断：一键标红违反魔方规则的格子并提示原因
- 复制配色：把当前 54 格配色复制成文本，方便排查
- 求解还原：基于 Kociemba 两阶段算法生成最短还原步骤

## 使用
浏览器直接打开 `index.html` 即可，无依赖、无需联网。求解器（rubik-solver / Kociemba）已内联在 HTML 中。

## 来源
本工具原为「拾遗集」站点（resource-hub）中的页面，抽出来作为独立单文件版本。
